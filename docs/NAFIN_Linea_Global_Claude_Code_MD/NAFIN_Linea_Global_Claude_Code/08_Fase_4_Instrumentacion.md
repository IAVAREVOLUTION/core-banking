# Fase 4 — Instrumentación

## Objetivo
Reutilizar la pantalla actual `Validación de Cláusulas Fiduciarias`, pero para Línea Global NAFIN presentarla como `Validación de Formalización`.

## Datos de Formalización
- No. Contrato / Convenio
- Intermediario
- Monto Autorizado
- Fecha Firma
- Fecha Inicio
- Fecha Vencimiento
- Representante IF
- Representante NAFIN

## Checklist de Instrumentación
Debe provenir del motor de requisitos/configuración existente.

Ejemplos:
- Contrato / Convenio firmado
- Poderes vigentes
- Acuerdo de autorización
- Condiciones precedentes cumplidas
- Esquema operativo configurado
- Expediente completo

## Resultado
`LISTA PARA LIBERACIÓN`

## Regla
No exigir Cláusulas Fiduciarias específicas del producto BANOBRAS cuando el producto sea Línea Global NAFIN.

## Autorización de Fase
Reutilizar validación de requisitos, validación de pantallas, autorización y generación de cargos desde Taller de Producto.
